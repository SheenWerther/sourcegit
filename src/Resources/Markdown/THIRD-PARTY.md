# 第三方资源

Markdown 预览使用的前端库和字体，随程序打包，离线可用。更新时替换文件并同步修改本表。

| 文件 | 来源 | 版本 | 授权 |
|---|---|---|---|
| `markdown-it.min.js` | [markdown-it](https://github.com/markdown-it/markdown-it) | 14.3.3 | MIT |
| `katex.min.js`、`katex.min.css`、`auto-render.min.js`、`fonts/KaTeX_*` | [KaTeX](https://github.com/KaTeX/KaTeX) | 0.16.47 | MIT |
| `highlight.min.js` | [highlight.js](https://github.com/highlightjs/highlight.js) | 11.12.0 | BSD-3-Clause |
| `mermaid.min.js` | [Mermaid](https://github.com/mermaid-js/mermaid) | 11.17.2 | MIT |
| `fonts/open-sans-*.woff` | Open Sans，取自 [MarkText](https://github.com/marktext/marktext) | v27 | Apache-2.0，见 `fonts/open-sans-LICENSE.txt` |
| `fonts/DejaVuSansMono*.ttf` | DejaVu Sans Mono，取自 [MarkText](https://github.com/marktext/marktext) | - | Bitstream Vera 衍生授权，见 `fonts/DejaVuSansMono_LICENSE` |

`preview.css` 的字号、间距、配色参考 MarkText（MIT）的 Cadmium Light 主题和 Prism light 代码配色，样式文件本身是本项目自己写的。

`preview.html`、`preview.css`、`preview.js` 是本项目自己的文件。
